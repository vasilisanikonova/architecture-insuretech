# Проблемы
**Первая проблема**
Наиболее критичным узким местом в системе является сервис core-app. Это монолитное приложение, которое не только предоставляет информацию о страховках, но и отвечает за интеграцию с платёжным сервисом. Партнёры обращаются к нему, он служит витриной для потенциальных клиентов, и, к сожалению, может выйти из строя в самый неподходящий момент, что повлечет за собой проблемы для всех зависимых сервисов.

**Вторая проблема**
Необходимо дублировать данные из базы данных. С одним экземпляром существует высокая вероятность их потери, и это не те 15 минут, о которых говорит бизнес.

**Третья проблема**
Отсутствие ограничений для API партнёров может привести к перегрузке системы, так как они могут чрезмерно нагружать её главный компонент.

**Четвёртая проблема**
Сервисы ins-product-aggregator и ins-comp-settlement могут замедлять работу системы. Хотя это не гарантировано, такая вероятность существует.

**Пятая проблема**
Долгое время обработки запросов в приложении связано с тем, что они обрабатываются непосредственно в core-app. Если он начинает тормозить, это негативно сказывается на производительности всей системы для клиентов.
